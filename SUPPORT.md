# Support

Use GitHub issues for support:

- Bug reports: include macOS version, TrimControl version, terminal backend, Neovim path, and the file extension you tried to open.
- Release/install problems: include whether you installed from a DMG, Homebrew cask, or a local build.
- LaunchServices/defaults problems: include the relevant extension and whether **Apply all defaults** or **Default Openers** was used.

Do not include private file contents, secrets, or sensitive file paths in public issues.
